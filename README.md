# Galactic Pest Control — Prototype Lab

Static GitHub Pages site containing three standalone HTML files:

- `index.html` — landing page
- `ecosystem-simulator.html` — ecosystem simulator
- `forest-prototype.html` — interactive forest

## Deploy

1. Upload all three `.html` files to the root of your GitHub repository (or replace the existing files). `README.md` is optional.
2. Go to **Settings → Pages** in your repository.
3. Under **Build and deployment**, select **Deploy from a branch**, your published branch (usually `main`), and **/(root)**. Save.
4. Visit the GitHub Pages URL for your repository. `index.html` is the landing page; the two buttons open the other HTML files.

The pages use relative links, so they also work when GitHub Pages serves the site under a repository subpath. Both prototypes are self-contained and need no separate assets.
